# Scriptler

AD otomasyonu için PowerShell betikleri. Her betik `Get-Help .\betik.ps1 -Examples` ile kullanım örneklerini gösterir. Değişiklik yapan betiklerde önce `-WhatIf` ile çalıştırın. `ornek-kullanicilar.csv` dosyasındaki kişiler ve alan adı tamamen kurgusaldır (`example.local`); kendi alan adınıza göre düzenleyin.
